## Aula 1 - Tipos e Variáveis

  Tipos de Dados
No Java, existem algumas palavras reservadas para a representação dos tipos de dados básicos que precisam ser manipulados para a construção de programas. Estes tipos de dados são conhecidos como tipos primitivos(Primitive Types).

## Os oito tipos primitivos em java são:
    int, byte, short, long, float, double, boolean e char - esses tipos não são considerados objetos, e portato representam valores brutos. Eles são armazenados diretamente na pilha de memória. (Memory stack).
