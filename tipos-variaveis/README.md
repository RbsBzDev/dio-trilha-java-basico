## Aula 1 - Tipos e Variáveis

  Tipos de Dados
No Java, existem algumas palavras reservadas para a representação dos tipos de dados básicos que precisam ser manipulados para a construção de programas. Estes tipos de dados são conhecidos como tipos primitivos(Primitive Types).

## Os oito tipos primitivos em java são:
    int, byte, short, long, float, double, boolean e char - esses tipos não são considerados objetos, e portanto representam valores brutos. Eles são armazenados diretamente na pilha de memória. (Memory stack).

Tabela de Tipos Primitivos e seus valores:

Tipo       Memória     Valor Mínimo     Valor Máximo
byte        1 byte      -128              127
short       2 byte      -32768            32767
int         4 bytes     -2147483648       2147693647
long        8 bytes     -9223732036...    0223372036...
float       4 bytes     1.4E-45           3.4028235e38
double      8 bytes     4.9E-324          1.797693123...
boolean     1bit        0 ou '\u0000'     65.535 ou '\uffff' 
char        2bytes       false             true
